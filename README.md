# Qué usan los devs junior en 2025: análisis de la encuesta de Stack Overflow

> **Estado: en construcción.** Este README se completa a medida que avanza el proyecto.

## Por qué este proyecto
Quiero entender qué tecnologías y condiciones de trabajo aparecen entre desarrolladores con poca experiencia profesional, y cómo se comparan con el resto del mundo y con Latinoamérica. Es también mi proyecto de práctica para SQL, Python y Power BI.

## Preguntas que quiero responder
1. ¿Qué lenguajes y herramientas usan más las personas con poca experiencia profesional?
2. ¿Cómo cambia la modalidad de trabajo (remoto, híbrido, presencial) según la experiencia?
3. ¿Qué tecnologías usan quienes trabajan en datos (SQL, Python, otras)?
4. ¿Cuánto se usa IA en el trabajo y cómo cambia según la experiencia?
5. ¿Cuántas respuestas hay de Chile y Latinoamérica y qué tan comparables son con el resto?

## Datos
Stack Overflow Annual Developer Survey 2025, licencia ODbL 1.0. Instrucciones de descarga en [`data/README.md`](data/README.md).

**Limitación importante:** la encuesta es voluntaria y de autoselección, así que no representa a todos los desarrolladores.
