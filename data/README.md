# Datos

Los datos originales **no se incluyen en este repositorio** (pesan más de 100 MB). Se descargan desde la fuente oficial.

## Cómo obtenerlos
1. Entra a https://survey.stackoverflow.co/
2. Abre la sección de resultados de **2025** y descarga el archivo de datos (CSV).
3. Descomprime y guarda el CSV en `data/raw/`.

## Fuente y licencia
